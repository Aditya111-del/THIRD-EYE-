# THIRD EYE — Frontend

Modern, AI-native frontend for **THIRD EYE**, featuring interactive terminal emulator stages, environment/session explorers, and an AI context assistant panel.

## Features
- **Multi-Session Explorer**: Manage SSH, container, and local shell sessions.
- **Interactive Terminal Stage**: Real-time terminal output, prompt display, command history, and shortcuts (`Ctrl+C`, `Ctrl+L`).
- **AI Context Assistant**: Live incident detection, GPT-4o root-cause diagnosis, and one-click shell command execution.

## Getting Started
```sh
npm install
npm run dev
```
